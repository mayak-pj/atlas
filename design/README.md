# Макет

`mockup/*.dc.html` — исходники интерактивного макета (8 экранов). Каждый файл: HTML-разметка экрана + стили в `<style>`
+ небольшой скрипт с поведением. Это **референс** для Qt-интерфейса: брать цвета, раскладку, состав блоков, тексты.
Переносить HTML в приложение не нужно.

| Файл | Экран |
|---|---|
| Main.dc.html | Вход по фамилии |
| Compare.dc.html | Сравнение (1/2 фото, синхронный зум, листание, отметки, сводка) |
| Import.dc.html | Импорт из письма и план копирования |
| Database.dc.html | База типов, поиск, архив с анимацией печати |
| Rules.dc.html | Правила |
| Comments.dc.html | Комментарии |
| Dashboard.dc.html | Дашборд |
| Draft.dc.html | Черновик и письмо |

Описание экранов словами — `docs/UI_SPEC.md`.
