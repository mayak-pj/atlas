# Экраны Atlas

Исходники макета — `design/mockup/*.dc.html` (HTML + разметка). Это **референс внешнего вида и раскладки**,
а не код для переноса. Цвета, отступы, состав блоков — брать оттуда.

## Тема
| Токен | Цвет | Где |

| panel | #171A1F | панели |
| panel-2 | #20252D | кнопки |

| type2 | #F2A93B | второй и следующие типы, «новое» |

| remark | #C59CFF | замечания |

Шрифт — Segoe UI 9–10 pt; SN и пути — Consolas. Скругления 7–10 px. Шрифты и цвета — через `core/theme/tokens.json`.
Можно сделать тему ещё лучше, но токены и структуру не ломать.

## Общая оболочка
- **Верхняя полоса:** ATLAS · вкладки (Сравнение, Импорт, База типов, Правила, Комментарии, Дашборд, Черновик) ·
  кто онлайн · тег пользователя · шестерёнка (Настройки, там же История).
- Вкладка «Правила» пульсирует янтарной точкой, пока есть непрочитанные; у «Комментариев» — счётчик.
- **Строка контекста:** бейдж A/B (можно скрыть в настройках) › Проект › Устройство › Деталь · путь к папке.

## 1. Вход (`Main.dc.html`)
Теги фамилий (цветной кружок с инициалами + фамилия), «+ Добавить себя», «Войти как …».
Блок «С вашего последнего входа»: новые правила, комментарии, непроверенные папки. Справа «Сейчас в работе» и последние проверенные папки.

## 2. Сравнение (`Compare.dc.html`) — главный экран
- **Слева:** «Новые — не проверены» (папки после копирования), «Проверено на этой неделе» (итог, кто, когда), кто над чем работает.
- **Два режима просмотра:** «Сравнение» (раскладки, эталон, листается одно окно) и «Ракурсы» (см. ниже); в «Сравнении» зум синхронный, его можно выключить. В макете переключателя нет: кнопки «Сравнение» и «Ракурсы» стоят первыми в панели инструментов.
- **Панель инструментов, два ряда** (в один не помещается при ширине окна 1024): режим, раскладка **1 / 2 / 3 / 4** (цифры, «N фото» — в подсказке; больше 4 нет), зум −/+, «Вписать», «Синхронно»; ниже — поворот против и по часовой стрелке (значки рисуются кодом, клавиши PgUp и PgDown), «Найти такую же деталь», Вырезать, Обвести, Подпись, «+ В базу типов».
- **Режим 1 фото — «листание»:** одно большое окно. ←/→ (и удержание стрелки) быстро листают, зум и место сохраняются —
  видно, как меняется плата. Пробел (удержание) — показать эталон на этом же месте («мигалка»).
- **Режим 2–4:** слева эталон (тип из базы или прошлая проверка), справа текущие. Всё синхронно. Листается только одно окно — активное.
- **Режим «Ракурсы»:** окна со всеми ракурсами одного SN, до 4, столько, сколько их бывает в папке; кнопок выбора ракурсов нет. Листание меняет все окна сразу. Зум и место у каждого окна свои, кнопки «Синхронно» в этом режиме нет. Пара определяется по имени файла `артикул_ракурс_SN[_окончание]`. SN идут по артикулу и SN, на ленте одна миниатюра на SN. Отметка ставится на фото активного окна. Раскладки, эталона и «Найти такую же деталь» в этом режиме нет.
- **«Найти такую же деталь»:** находит такую же деталь из последних проверок и открывает её для сравнения.
- **Поворот на 90°:** файл не меняется, поворот запоминается на фото. В «Сравнении» поворачиваются все окна вместе, в базу записываются только фото текущей папки, эталон — нет. В «Ракурсах» — только активное окно. При листании у каждого фото свой поворот.
- Колесо — зум к курсору, перетаскивание — сдвиг, двойной клик — вписать.
- **Лента миниатюр** с цветными точками отметок.
- **Отметки:** Тип 1 / Тип 2 / … / Дефект / Замечание (клавиши 1, 2, …, D, R). Для дефекта — SN (подставляется из имени файла, можно исправить) и вид из справочника.
- **Справа — сводка по детали:** плашка «проблемная деталь», типы с датами, дефекты и замечания (SN, вид, дата, кто),
  счётчики текущей папки, «Завершить → письмо».

## 3. Импорт (`Import.dc.html`)
Письма Outlook → план копирования (источник, проект, куда, сколько фото, статус) → новые детали подсвечены, «Создать папку» →
карточки-сводки по скопированным деталям → «Открыть сравнение».

## 4. База типов (`Database.dc.html`)
Мгновенный поиск, фильтры, сетка карточек (фото с красной обводкой и подписью «ТИП 2»). Карточка типа справа, все типы устройства.
**«В архив»:** фото плавно в ч/б → падает красная печать «В АРХИВЕ» с лёгким «ударом». «Вернуть из архива» — обратно в цвет.
Архивные — всегда внизу выдачи.

## 5. Правила (`Rules.dc.html`)
Список с фильтрами, «НОВОЕ» на непрочитанных, автор-тег, привязка к детали. Справа форма нового правила с фото.

## 6. Комментарии (`Comments.dc.html`)
Сообщение + фото (вставка из буфера), адресат, привязка к детали, «ошибка ранее», срок жизни. Кнопки «Открыть в сравнении», «Ответить», «Готово».

## 7. Дашборд (`Dashboard.dc.html`)
Показатели, детали с наибольшим числом замечаний, виды замечаний, детали без проблем. Будет наполняться.

## 8. Черновик (`Draft.dc.html`)
Свободные заметки (как раньше) · автосписок найденного (тип/дефект/замечание, SN, миниатюра с обводкой) ·
предпросмотр письма-ответа · «Записать в Excel», «Разложить по папкам типов», «Открыть в Outlook как ответ» (не отправлять автоматически).
