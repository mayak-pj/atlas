# Atlas — выезд на целевую машину (после этапа 5)

> [!info] Как пользоваться
> Файл для Obsidian: галочки `- [ ]` ставятся кликом, цветной текст — обычный HTML.
> Идите **сверху вниз**. Каждый пункт: <span style="color:#3e8bff">**что сделать**</span> → <span style="color:#30a46c">**что ожидается**</span> → <span style="color:#e5484d">**если не так**</span>.
> Всё занимает около **1,5–2 часов** вместе с замером фото (он идёт сам, 5–15 минут). Администратор не нужен, ничего не устанавливается.

> [!warning] Главное правило репозитория
> <span style="color:#e5484d">**Настоящие названия двух видов проектов (аббревиатуры) нельзя писать в git, в код и в файлы проекта.**</span>
> В программе они — `A` и `B`. Настоящие подписи пишутся **только** в `config\local.json` на целевой машине (раздел 3.3). Письма, скриншоты и образцы возите мне **не через репозиторий** (положите в `_refs\vyezd\` — эта папка в git не попадает).

## 1. Что скопировать на флешку

Нужен **один файл**. Остальное программа создаёт сама.

- [ ] **Скачать сборку из GitHub Actions** (на Mac, с интернетом):
  1. Открыть готовую проверенную сборку: <https://github.com/mayak-pj/atlas/actions/runs/41332907221> (все 717 тестов и проверка на Windows 7 пройдены). Список всех запусков — <https://github.com/mayak-pj/atlas/actions/workflows/build-windows.yml>.
  2. Если берёте другой запуск — только **зелёный** и не старше «Функция add_folder: кнопка «Добавить папку…»…» (в более ранних нет кнопки). Красный или жёлтый — не брать.
  3. Внизу страницы, раздел **Artifacts** → скачать **`atlas-win7-x64`**.
  4. GitHub отдаёт zip в zip: внутри скачанного файла лежит **`atlas-win7-x64.zip`** — он и нужен.
- [ ] Положить на флешку **`atlas-win7-x64.zip`** (≈ 25 МБ; FAT32 подходит).
- [ ] <span style="color:#8b95a3">Необязательно:</span> положить на флешку этот файл (`VYEZD_ETAP5.md`), распечатать или открыть на телефоне.
- [ ] <span style="color:#8b95a3">Необязательно:</span> пустая папка `reports_назад` на флешке — туда удобно скопировать отчёты на обратном пути.

> [!tip] Что на целевой машине подготовить заранее
> - Путь к сетевой папке с **настоящими фото** (лучше 500+ штук) — для замера скорости.
> - Пустая **тестовая** подпапка на сетевом диске (например `R:\Atlas\test`) — для проверки базы. Рабочие данные проверка не трогает.
> - <span style="color:#f5a524">Если есть второй компьютер</span> с доступом к той же сетевой папке — для проверки «два ПК» (раздел 2.4, пункт в).

## 2. Что запускать на целевой машине

### 2.1 Подготовка (2 минуты)

- [ ] Скопировать `atlas-win7-x64.zip` с флешки в **свою локальную папку** (например `C:\Users\<вы>\Atlas`). Не на сетевой диск — это отдельный шаг (2.5).
- [ ] Правый клик на zip → **Свойства** → внизу кнопка **«Разблокировать»** → ОК. <span style="color:#8b95a3">(Если кнопки нет — файл не заблокирован, всё хорошо.)</span>
- [ ] Правый клик → **Извлечь всё…** → получится папка `atlas` с `atlas.exe` и `.bat`-файлами.
- [ ] Пути с русскими буквами и пробелами — **можно**, это тоже проверка.

### 2.2 Программа запускается (5 минут) — `check_win7.bat`

- [ ] Запустить **`check_win7.bat`** (двойной клик). Окно откроется и закроется само, ничего не нажимать.
  - <span style="color:#30a46c">Ожидается:</span> «Код завершения: 0».
  - <span style="color:#e5484d">Если не 0:</span> сфотографировать окно, взять файлы из `logs\` и `reports\logs\`.
- [ ] Открыть **`reports\selfcheck.txt`** и записать (или скопировать целиком) строки:
  - [ ] «Экран» — разрешение и DPI (это закрывает `OPEN_ITEMS` №8)
  - [ ] «Шрифты»
  - [ ] «папка кэша фото»
  - [ ] «чтение L1 / L2 / L3» (миллисекунды на фото 3456×5184)
  - [ ] «кэш: …»
- [ ] Открыть **`reports\*.png`** и сравнить с тем, что видно на экране у вас: шрифт нормальный, ничего не обрезано.
- [ ] Запустить **`atlas.exe`**: «+ Добавить себя» → фамилия → «Войти».
  - <span style="color:#30a46c">Ожидается:</span> окно с вашим тегом и вкладками **«Сравнение»**, **«База типов»**, **«Привет»**.
  - [ ] Закрыть программу.

### 2.3 Настройка путей (3 минуты) — `config\local.json`

Создайте файл **`config\local.json`** рядом с `atlas.exe` (блокнотом, кодировка UTF-8). Он **не** входит в сборку и не попадает в git. Пример:

```json
{
  "database": { "path": "var/atlas.sqlite" },
  "type_db": { "dir": "var/type_db" }
}
```

- [ ] На **первый прогон оставьте локальные пути** как выше (всё лежит рядом с программой, в `var\`).
- [ ] <span style="color:#8b95a3">Когда дойдёте до 2.5 (сеть), поменяйте на сетевые, например</span> `"R:\\Atlas\\db\\atlas.sqlite"` и `"R:\\Atlas\\types"` <span style="color:#8b95a3">(в JSON обратная косая — двойная).</span>
- [ ] <span style="color:#8b95a3">Свои подписи видов проектов (настоящие вместо A/B) — добавить строку</span> `"project_kinds": ["<подпись 1>", "<подпись 2>"]`. <span style="color:#e5484d">Только в этом файле, нигде больше.</span> Тогда в `add_folder.bat` вид вводится **этой** подписью.

### 2.4 База на сетевом диске (главный риск) — `check_db.bat`

Нужна тестовая подпапка на сетевом диске, например `R:\Atlas\test`.

- [ ] **а. Один ПК.** `check_db.bat` → ввести путь → ждать 2 минуты.
  - <span style="color:#30a46c">Ожидается:</span> код 0, в отчёте «ДАННЫЕ ЦЕЛЫ», «потеряно: 0».
  - [ ] Скопировать `reports\dbcheck_ИМЯ-ПК.txt` в файл **`а.txt`** (отчёт перезаписывается следующим прогоном!).
- [ ] **б. Обрыв сети.** Запустить ещё раз; примерно на **30-й секунде** на минуту отключить сетевой кабель или адаптер, потом вернуть. Программа ждёт сеть ещё до 2 минут.
  - <span style="color:#30a46c">Ожидается:</span> код 0, «ДАННЫЕ ЦЕЛЫ», «потеряно: 0».
  - [ ] Скопировать отчёт в **`б.txt`**.
- [ ] **в. Два ПК** (если есть второй): запустить на обоих с одной и той же папкой, разница **не больше 10 секунд**.
  - [ ] Скопировать отчёты с обоих ПК в **`в1.txt`**, **`в2.txt`**.
  - <span style="color:#8b95a3">Нет второго ПК — пропустить, отметить «нет второго ПК» в разделе 3.</span>

> [!bug] Если «потеряно» не ноль или код не 0
> <span style="color:#e5484d">Не продолжайте на этой базе.</span> Привезите отчёт как есть — это самый важный результат поездки.

### 2.5 Запуск с сетевого диска (5 минут)

- [ ] Скопировать папку `atlas` на сетевой диск и запустить `atlas.exe` **через букву диска** (`R:\…\atlas.exe`).
- [ ] Если известен — запустить также **по UNC** (`\\сервер\…\atlas.exe`).
  - <span style="color:#30a46c">Ожидается:</span> окно открывается, вход работает.
  - [ ] Записать: **мешает ли антивирус** (всплывающее окно, блокировка, долгая проверка) и **как называется антивирус** (`OPEN_ITEMS` №9).
  - <span style="color:#e5484d">Если блокирует запуск с сети:</span> записать точный текст окна.

### 2.6 Скорость просмотра фото (5–15 минут) — `check_view.bat`

- [ ] `check_view.bat` → ввести папку с **настоящими фото на сетевом диске** (500 штук и больше). Папка только читается. Окна открываются сами, ничего не нажимать.
  - <span style="color:#8b95a3">Нет настоящей папки — оставить пустым: создадутся тестовые фото (нужно 5 ГБ на диске, потом удалятся). Это лучший случай: про сетевой диск такие цифры ничего не говорят.</span>
  - <span style="color:#30a46c">Ожидается:</span> код 0; цель — листание без задержки с превью, чёткость не позже 300 мс после остановки.
  - [ ] Забрать `reports\viewbench_ИМЯ-ПК.txt`.

### 2.7 Посмотреть глазами на настоящих фото (30–40 минут)

> [!note] Зачем
> Всё это на настоящем экране ещё ни разу не открывалось. Нужно понять, что **тормозит, обрезано, неудобно или непонятно**. Ошибок бояться не надо: любая находка — полезный результат.

**Шаг 1. Внести папку в базу** (импорта из письма ещё нет, это временное средство)

- [ ] Запустить `atlas.exe`, войти. Слева над списком папок — кнопка **«Добавить папку…»**. Нажать.
- [ ] В окне **вставить путь** к папке с фото (можно с кавычками, `\\сервер\…` и с русскими буквами) или нажать «Обзор…». Нужна папка с **20+ фото** `.jpg`; она только читается.
  - <span style="color:#30a46c">Ожидается:</span> внизу «Фото в папке: N»; вид, проект, устройство, деталь и дата подставлены по пути — **проверить и поправить**, если угадало неверно.
  - [ ] Записать: <span style="color:#f5a524">угадала ли подсказка проект, устройство, деталь и дату?</span> Это важно: на основе ответа подстрою разбор пути.
  - [ ] Нажать «Добавить» → папка открывается в сравнении и появляется в «Новые» слева, внизу окна сообщение «Папка добавлена».
  - <span style="color:#e5484d">Если ошибка:</span> записать текст (внизу окна) или скриншот окна «Добавить папку».
  - <span style="color:#8b95a3">Запасной способ, если кнопка не открылась:</span> `add_folder.bat` (спросит то же самое по очереди, итог в `reports\addfolder.txt`).
- [ ] Запустить `atlas.exe` → войти → слева в списке **«Новые — не проверены»** должна быть эта папка → клик по ней.

**Шаг 2. Листание и чёткость** (то, что мы правили сегодня)

- [ ] Нажать **«1»** (один большой экран) → колесо мыши: увеличить фото в 4–5 раз на мелкой детали.
- [ ] Листать **← / →**. Следующее фото должно открываться **сразу и чётким**, без размытия «с задержкой».
- [ ] **Удерживать стрелку** (быстрое листание): не должно «залипать».
  - Записать: <span style="color:#f5a524">видно ли размытие после перелистывания? сколько примерно секунд?</span>

**Шаг 3. Отметки и поворот**

- [ ] Клавиши **1, 2, 3** — «Тип N»; **D** — «Дефект» (вид и SN подставляются); **R** — «Замечание». Поставить по 2–3 разных отметок на разных фото.
- [ ] **PgUp / PgDown** — поворот фото; листать дальше — поворот сохраняется для этого ракурса.
- [ ] Точки отметок на ленте миниатюр внизу видны и нужного цвета.

**Шаг 4. Разметка** (4.1)

- [ ] **«Обвести»** — нарисовать красный эллипс мышью; **«Подпись»** — щелчок и текст; **«Вырезать»** — рамка «ножницами».
- [ ] **Ctrl+Z / Ctrl+Y** — отмена и повтор. Сдвиг фото при включённом инструменте — **Shift + мышь**.

**Шаг 5. «+ В базу типов»** (4.2)

- [ ] Нажать **«+ В базу типов»** → заполнить окно (тип или дефект, номер, отличие — обязательно, артикул) → сохранить.
  - <span style="color:#30a46c">Ожидается:</span> окно открывается, закрывается без ошибок.
  - [ ] Проверить: в папке `var\type_db\…` (или в сетевой, если вы поменяли путь) появились `_photo.jpg` и, если была рамка, `_crop.jpg`.

**Шаг 6. Вкладка «База типов»** (4.3, 4.4)

- [ ] Открыть вкладку «База типов»: карточка видна, фото на месте.
- [ ] Поиск: набрать часть названия, артикула, описания — результат **мгновенно**. Регистр и «е/ё» не важны.
- [ ] Кнопка **«В архив»**: фото плавно становится серым, падает печать «В АРХИВЕ», карточка уходит вниз. «Вернуть из архива» — обратно в цвет.
  - Записать: <span style="color:#f5a524">анимация плавная или рывками?</span> Если рывками — в `config\local.json` добавить `"ui": { "animations": false }`.

**Шаг 7. Сводка по детали и плашка «Ранее были замечания»** (5.1, 5.2)

- [ ] В первой папке поставить **2–3 отметки «Дефект» или «Замечание»** (шаг 3).
- [ ] Нажать **«Добавить папку…»** **ещё раз**: **та же деталь** (название — точь-в-точь, регистр не важен), **другая папка** с фото, другая дата.
- [ ] Открыть вторую папку.
  - <span style="color:#30a46c">Ожидается:</span> справа **красная плашка «Ранее были замечания — будьте внимательнее»** («N замечания за 180 дней · последнее ДД.ММ»), типы с датами, список дефектов/замечаний (SN, вид, дата, кто); внизу окна на 15 секунд уведомление «…Будьте внимательнее».
- [ ] Для проверки: внести третью папку с названием детали **длиннее** на пару слов — плашки быть **не** должно (по решению: похожие названия не учитываются).
  - Записать: <span style="color:#f5a524">заметно ли уведомление внизу окна? не закрывается ли оно другими сообщениями?</span>

**Шаг 8. Скриншоты**

- [ ] 3–5 снимков экрана (клавиша **PrintScreen**, затем вставить в Paint и сохранить): окно сравнения с фото, «База типов», панель справа с плашкой, любое окно с ошибкой или обрезанным текстом.
