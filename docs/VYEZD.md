# Выезд: проверка Atlas на целевой машине

Один файл на весь выезд. Открыть: двойной щелчок по `vyezd.bat` в папке с `atlas.exe` (откроется в Блокноте).
Ставьте крестик в скобках: `[ ]` → `[x]`. Рядом с пунктом есть место для записи — пишите после стрелки `->`.
Когда закончите: «Файл» → «Сохранить как…» → `vyezd_заполнено.md` в папку `reports`, папку привезти целиком.

Атлас только читает фото, свои файлы не меняет. Что уже проверено раньше (запуск, база на сетевом диске, обрыв сети,
два ПК, установка/обновление, Excel/Outlook) — здесь не повторяется.

Если какой-то пункт не получился — не пропускайте молча: запишите, что случилось, и идите дальше.
